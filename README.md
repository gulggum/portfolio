# 🏢 My Company Portfolio

“저희 회사를 소개합니다.”

개인 포트폴리오를 **하나의 회사처럼 구성한 인터랙티브 웹사이트**입니다.  
사용자는 회사에 입장해 각 직원(기능)을 통해 저를 알아갈 수 있습니다.

---

## ✨ Concept

- 👩‍💼 저는 "대표"
- 🤖 각 직원은 저의 역량을 담당
- 💬 클릭 시 대화 형태로 정보 제공
- 🏢 회사에 입장하는 경험 중심 UI

---

## 🛠 Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- React Router
- Vercel (배포)

---

## 🧩 Features

- 인트로 (회사 입장)
- 사무실 인터랙션 UI
- 직원(캐릭터) 기반 정보 구조
- 질문 기반 응답 (AI 컨셉)
