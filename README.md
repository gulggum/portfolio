# My Company Portfolio

"면접관이 AI 봇에게 직접 물어보는 포트폴리오"

개인 포트폴리오를 하나의 회사처럼 구성한 인터랙티브 웹사이트입니다.
사무실 공간에 배치된 AI 봇들을 클릭해 Claude API 기반 대화로 저를 알아갈 수 있습니다.

---

## Concept

- 저는 "대표", 각 봇은 저의 역량을 담당하는 직원
- 봇 클릭 시 Claude API와 연결된 채팅창으로 자유롭게 질문 가능
- 사이드바에서 정리된 정보(소개, 기술스택, 프로젝트, 연락하기) 확인 가능
- 인트로 → 사무실 입장 → 봇과 대화하는 경험 중심 UI

---

## Tech Stack

- React + TypeScript
- Vite
- styled-components
- React Router
- Claude API (Anthropic)
- Vercel (배포 + Serverless Function)

---

## Features

- 인트로 애니메이션 (회사 입장)
- 사무실 배경 위 봇 캐릭터 배치 (좌우 스크롤)
- 봇별 Claude API 시스템 프롬프트 분리
- 소개 / 기술스택 / 프로젝트 캐러셀 / 연락하기 모달
- 다크 / 라이트 테마 토글
- 반응형 (PC 사이드바 / 모바일 하단 탭바)
- API 키 보호 (Vercel Edge Function)
